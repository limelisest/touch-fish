# Windows 实机验证清单

当前代码已在 Linux 构建机完成 Windows 交叉构建与纯业务测试；以下项目需要在 Windows 10/11 实机验证。

- [ ] 设置快捷键后可在前台与后台触发
- [ ] 快捷键冲突时显示错误且不覆盖原配置
- [ ] 拖动准星可选择普通 QQ 主窗口
- [ ] “定位窗口”可恢复并聚焦 QQ
- [ ] Chrome/Edge 安装式 Telegram Web App 能读取浏览器 App ID
- [ ] Telegram 标题或当前聊天变化后仍能匹配
- [ ] 普通 Chrome 标签页无法取得 App ID 时正确回退到标题关键词
- [ ] 第一次按键只最小化当前未最小化的目标窗口
- [ ] 第二次按键只恢复由 TouchFish 最小化的窗口
- [ ] 关闭主窗口后托盘和老板键继续工作
- [ ] 配置在重启 TouchFish 和重启 Windows 后可重新载入
- [ ] 普通权限程序面对管理员权限窗口时显示合理结果
